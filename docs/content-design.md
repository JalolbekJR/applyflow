# Content Design

## Principles

- Write directly.
- Explain why a field exists.
- Use candidate-facing language, not internal hiring jargon.
- Keep vacancy requirements specific.
- Separate essentials from nice-to-have skills.
- Avoid exaggerated culture claims.
- Avoid vague calls to action.
- Use errors that help the candidate recover.
- Do not invent statistics, testimonials, or hiring guarantees.

Avoid words and phrases such as rockstar, ninja, revolutionary, next-generation, unlock your potential, and join our journey.

## Field Labels And Hints

| Field | Label | Hint |
| --- | --- | --- |
| Full name | Full name | Use the name you want us to use when contacting you. |
| Email | Email address | We use this for application updates and duplicate-submission checks. |
| Phone | Phone number | Optional. Add it only if phone contact is okay. |
| Profile link | Portfolio, GitHub, or LinkedIn | Add one link that best represents your work. |
| Preferred contact | Preferred contact method | Tell us how you would rather hear from us. |
| CV | CV upload | PDF only. Maximum planned size: 5 MB. |
| Skills | Relevant skills | Add the skills most connected to this role. |
| Message | Short message | Optional. Use this for context not obvious in your CV. |

## Error Examples

- Enter your full name.
- Enter an email address in the format name@example.com.
- Add a valid link starting with `https://`.
- Choose a preferred contact method.
- Upload a PDF file under 5 MB.
- Add at least one relevant skill.
- Review the privacy acknowledgement before submitting.
- We could not save your draft. Your answers are still visible. Try again.

## Confirmation Copy

Example:

> Your application for Frontend Developer has been submitted. Your application reference is AF-9Q2K-M7P4. Keep the separate status lookup secret private; it is the credential used to check status.

The final implementation should not promise response timing unless the business can meet it.

## Fictional Vacancy Outlines

### Frontend Developer

Summary: Build fast, accessible Nuxt interfaces for candidate-facing product flows.

Responsibilities:

- Implement responsive Vue and Nuxt pages.
- Connect frontend forms to REST APIs.
- Build validation, loading, error, and success states.
- Write unit and browser tests for critical flows.
- Collaborate on design tokens and component states.

Essential requirements:

- Vue 3 and Composition API.
- TypeScript basics.
- HTML and CSS fundamentals.
- REST API integration.
- Responsive and mobile-first implementation.
- Git workflow.

Nice to have:

- Nuxt server rendering experience.
- Playwright or Vitest.
- Accessibility testing.

### Backend Developer

Summary: Build secure Django APIs for vacancy and application management.

Responsibilities:

- Design Django models and DRF serializers.
- Implement draft and submission workflows.
- Validate uploads and protect private documents.
- Add PostgreSQL constraints and tests.
- Support Django Admin operations.

Essential requirements:

- Python and Django.
- Django REST Framework.
- PostgreSQL.
- Server-side validation.
- Automated tests.
- Git workflow.

Nice to have:

- Docker.
- OpenAPI documentation.
- Security testing for authorization and uploads.

### UI/UX Designer

Summary: Design a clear job application flow that reduces repetition and improves confidence.

Responsibilities:

- Audit existing application-flow problems.
- Create user flows and wireframes.
- Define mobile-first layouts.
- Build component variants in Figma.
- Annotate accessibility and form states.
- Prepare developer handoff.

Essential requirements:

- Information architecture.
- Wireframing and prototyping.
- Responsive design.
- Design systems.
- Accessibility basics.
- Clear product writing.

Nice to have:

- Usability testing facilitation.
- Developer collaboration.
- Portfolio case-study writing.
